Phase 2: The "Genesis" Mint
We don't want to spam the Solana network with 10,000 individual transactions (which is expensive and slow).
Batching: Group users into batches of 50.
Airdrop Tool: Use a script to call your issue_points function in bulk for the initial balances.
The "Shadow" Period: Run the new service in "read-only" mode for 48 hours to ensure the indexer is correctly picking up the initial mints.
